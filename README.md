# Clawpick Mechanical Lab

실제 인형 뽑기 머신의 노출 기구와 조작감을 브라우저에서 검증하는 물리
프로토타입입니다. Next.js 기반 UI와 React Three Fiber, Rapier 물리 엔진을
사용합니다.

## 구현 범위

- 공유 플런저와 회전 로커 링크로 움직이는 3지 단일 강체 곡선 집게
- 위치 서보 없이 방향·속도 제한·최대 축력으로 구동하는 플런저
- 기계적 끝단 전 3mm 축력 램프와 10% 유지 축력
- 관절 한계와 물리 콜라이더에 의한 집게 간섭 방지
- 윈치 길이 제어와 비신축 로프 제약을 이용한 승강
- 트롤리 이동 관성에 따른 케이블 진자 운동
- 상부 와이어 체결점에 매달린 집게 몸통의 자유로운 3축 회전
- 고정 측면 봉 위를 달리는 브리지와 그 위를 달리는 캐리지로 이루어진 갠트리.
  둘 다 prismatic 조인트로 축에 묶인 강체이고 조인트 속도 모터로 구동하므로
  정지 시 정착과 끝단 충격, 매달린 집게의 진자 반작용이 물리로 나타남
- 좌측 엔드 플레이트에 붙어 고정 레일 위의 바퀴를 돌리는 브리지 주행 구동부.
  기어케이스와 그 아래 매달린 모터가 브리지 질량의 26%를 차지하고, 케이스
  내측면이 캐리지의 좌측 기계적 끝단이므로 X축 이동 범위는 좌우 비대칭
- 단일 규격 원형 봉 5개와 흰색 나일론 홈 바퀴 8개. 좌측 2개만 구동륜이고
  봉 길이와 축 이동 범위는 지정하지 않고 캐비닛 내부 치수에서 도출
- ToysPop Mini 계열을 참고한 라운드 캐비닛, 강화유리, 간판과 서비스 하부장
- 렌더 프레임이 아닌 고정 60Hz 물리 스텝에서만 동작하는 상태 머신과 물리 쓰기
- React·three·Rapier 의존이 없는 순수 함수(`game/machineStep.mjs`)로 분리된
  단계 전이, 윈치 궤적, 트롤리 운동학
- 케이블 길이 오차, 흔들림 각도, 집게 간격 디버그 계측
- 메인 상단 모달에서 머신·승강부·집게·물리 구현 명칭을 찾는 번호식 부품 용어집
- 우측 인스펙터에서 물리 튜닝과 전환하며 렌더·콜라이더 공통 치수를 편집하는 부품 스펙 패널
- 위에서 내려다보기 위한 상단 덮개 토글

## 실행

Node.js `22.13.0` 이상이 필요합니다.

```bash
npm install
npm run dev
```

## 검증

```bash
npm run typecheck
npm run lint
npm test
```

`npm test`는 프로덕션 빌드와 함께 집게 기구학, 비신축 케이블, 숨은 파지
보정 제거 여부, 서버 렌더링을 검증합니다.

단계 전이·윈치·축 구동은 `game/machineStep.mjs`와 `game/driveAxis.mjs`가
순수 함수이므로 `tests/machine-step.test.mjs`에서 헤드리스로 한 라운드를
그대로 돌려 동작을 검증합니다.

`tests/drive-axis.test.mjs`는 편집 가능한 봉·바퀴 스펙을 슬라이더 전 구간에
걸쳐 스윕하며, 어느 값에서도 바퀴 홈이 봉에 접선으로 얹히고 플랜지가 봉을
감싸며 캐리지가 엔드 플레이트와 주행 구동부를 관통하지 않고 갠트리가 천장을
넘지 않으며 배출구와 가장 왼쪽 인형에 모두 도달하는지 확인합니다. 주행
구동부의 모터·단자함이 캐리지 스토퍼 면보다 안쪽으로 나오지 않는지와 브리지
질량 분배 합이 1인지도 같은 파일에서 검증합니다.

소스 문자열을 정규식으로 확인하는 기존 테스트는 이 방식으로 점진적으로
옮기는 중입니다.
